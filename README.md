Central Superstore – SQL Data Warehouse Project

📌 Project Overview

This project focuses on building a SQL-based Data Warehouse using the Central Superstore dataset.

The main goal is to organize and structure sales data to support efficient data management, querying, and business analysis.

The project demonstrates practical SQL skills, database development, data warehouse concepts, and analytical thinking.

🎯 Project Objectives

- Build and organize a SQL database.
- Design a structured Data Warehouse environment.
- Create database schemas and staging areas.
- Load and prepare data for analysis.
- Write SQL queries to extract meaningful business insights.
- Support business decision-making through data analysis.

📊 Dataset Description

The project uses the Central Superstore dataset, which contains retail sales information.

The dataset is provided in CSV format:

- "central_superstore.csv"

It serves as the source data for the Data Warehouse.

🛠️ Tools & Technologies

- SQL Server: Database management and development.
- SQL: Data definition, manipulation, and querying.
- SQL Server Management Studio (SSMS): Writing and executing SQL scripts.
- CSV: Source data format.

🏗️ Data Warehouse Development

The project includes the following development components:

- Database creation and configuration.
- Schema creation and organization.
- Staging schema preparation.
- Metadata management.
- Data loading using SQL.
- SQL-based data preparation and analysis.

🔄 Project Workflow

1. Database Setup: Create and configure the project database.
2. Schema Design: Organize database structures and create the staging schema.
3. Data Loading: Import the source CSV data into SQL Server.
4. Data Preparation: Prepare the data for further analysis.
5. SQL Analysis: Develop queries to explore the dataset and generate business insights.

💡 SQL Concepts & Techniques

- Database Creation
- Schema Management
- Conditional Object Creation
- Staging Tables
- BULK INSERT
- TRUNCATE TABLE
- SQL Data Manipulation
- Analytical Queries

▶️ How to Run the Project

1. Download or clone this repository.
2. Open SQL Server Management Studio (SSMS).
3. Open the SQL script located in the project folder.
4. Make sure the source CSV file is available.
5. Update the CSV file path in the "BULK INSERT" statement to match your local file location.
6. Execute the SQL script in SQL Server.
